## 1. 디자인 문제 정의 & 목표

### 1.1 현황 진단
| 강점 | 약점(개편 대상) |
| --- | --- |
| 화이트 프리미엄 톤·브랜드 일관 | "빠르게 잘 만든" 수준 — 디자인 시스템 깊이 부족(→Mantine으로 일부 해소) |
| 폭염 단계 시각화·정부기준 권위 | **IA가 온보딩 위저드 중심** — 일상 사용자의 상시 네비/딥링크 부재 |
| 리포트 자동화(PDF/Excel) 강력 | **모바일/현장 사용 미최적** — 데이터 밀집 테이블·차트가 작은 화면에서 무너짐 |
| KPI·시계열·외부비교 차트 | **다크모드 없음** · 위험지도 미구현(README 약속 미이행) · 현재날씨 미배선 |
| 멀티테넌트·관리자 대시보드 | 상태가 URL에 없음(공유·뒤로가기·새로고침 맥락 손실) |

### 1.2 비즈니스 목표
- **컴플라이언스 신뢰**: 고용노동부/기상청 기준의 권위가 화면에서 즉시 전달 → B2B 도입 결정 가속.
- **리텐션·일상화**: 위저드 1회성 → 매일 여는 대시보드로 전환(상시 네비·딥링크·알림).
- **브랜드 자산**: 케이웨더 = "안전·기상 데이터" 전문성의 시각적 각인 + 케이웨더몰 연계 강화.
- **현장 확장**: 모바일/태블릿으로 현장 작업반장까지 사용자 확대.

### 1.3 디자인 목표 (측정 가능)
1. **위험 인지 ≤1초** — 진입 즉시 현재 위험단계가 가장 강한 시각 위계.
2. **리포트 도달 ≤2클릭** — 일상 사용자가 분석/출력에 최소 동선.
3. **모바일 핵심 과업 100%** — 대시보드·위험확인·리포트 다운로드 모바일 완전 수행.
4. **접근성 WCAG 2.2 AA** — 안전 크리티컬 제품의 책임. 색맹 안전 단계색.
5. **시스템 일관성** — 모든 화면이 단일 토큰/컴포넌트에서 파생(하드코딩 0 지향).

### 1.4 성공지표(KPI)
- 활성 리텐션(주간 재방문), 대시보드→리포트 전환율, 모바일 세션 비중, A11y 자동검사 0 위반, 디자인 토큰 커버리지(%).

## 3. 디자인 원칙 (5)

1. **Compliance-grade Trust** — 정부 기준·출처·권위가 보이는 차분하고 정밀한 톤. 장식보다 근거.
2. **Glanceable Risk** — 위험단계가 항상 최상위 시각 위계. 색·크기·위치로 1초 판독.
3. **Responsive & Field-ready** — 데스크톱 밀집 ↔ 모바일 단순화가 같은 시스템에서 파생. 큰 터치·강대비·다크.
4. **Clarity over Decoration** — 데이터 명료성 최우선. 차트/표는 잉크를 줄이고 의미를 키운다.
5. **One KWeather** — 단일 토큰·단일 컴포넌트·단일 보이스. 브랜드와 몰까지 일관.

## 4. 리브랜딩 방향 (적극) — 새 비주얼 아이덴티티 ★다음 결정 게이트

> **불변 제약**: 폭염 5단계색(관심 #84cc16 / 주의 #facc15 / 경고 #f97316 / 위험 #dc2626)과 임계는 **안전 의미 전용**으로 고정. 브랜드 1차색이 이 색들과 충돌하지 않도록 설계.

### 컨셉 3안 (택1 필요)

**A. "Signal" (추천)** — 딥 잉크 네이비 베이스 + 케이웨더 스카이를 에너지 악센트로.
- 무드: 신뢰·관제·프리미엄. 다크모드와 천연 궁합. 단계색이 가장 또렷하게 산다.
- 1차(액션) = 정제된 Azure, 베이스 텍스트/표면 = Ink Navy, 악센트 = Sky.
```
라이트:  bg #F7F9FC  surface #FFFFFF  ink #0B2A4A  primary #0E6FB8  accent #1AA3E0
다크:    bg #0A1929  surface #0F2438  ink #E6EEF7  primary #3AA0E8  accent #5CC5F2
단계색:  연두/노랑/주황/빨강 (불변) — 브랜드 블루와 색상환상 분리되어 충돌 없음
```

**B. "Clear Sky"** — 밝고 통풍감, 케이웨더 스카이블루를 전면에. 가볍고 친근.
- 무드: 개방·헬스·접근성. 단, 밝은 블루가 '주의' 톤과 인접해 단계 대비 설계 주의 필요. 다크모드는 보조.

**C. "Control Room"** — 다크 퍼스트 운영 콘솔. 뉴트럴 차콜 + 강한 단계색 + 데이터 모노스페이스.
- 무드: 현장/관제 특화, 위험 강조 최강. 단, B2B 임원 친화·인쇄 리포트엔 라이트 변환 필수.

> **추천: A "Signal"** — (1) 단계색 보존 원칙과 가장 잘 양립(블루↔단계색 색상 분리), (2) 다크모드 내장 방향과 일치, (3) 케이웨더 브랜드 자산(네이비·스카이) 계승하면서 '적극' 정제, (4) 사무실(라이트)·현장(다크) 양립.

### 4.1 타이포그래피 (Pretendard 기반)
- Display(히어로 수치) / H1–H3 / Body / Caption / **Data-mono**(수치·코드·SN·시각 — `tabular-nums`).
- 모듈러 스케일 1.25, 한글 자간 −0.01em 유지, 큰 수치는 `font-feature: tnum`.

### 4.2 형태 언어
- Radius: 카드 16px / 컨트롤 10–12px / 알약 999px. Elevation: 2단(card/lift) + 다크용 보더-퍼스트.
- 모션: 150–200ms ease, 위험단계 전환만 강조 모션. `prefers-reduced-motion` 대응.
- 아이콘: `@tabler/icons-react`(이미 도입) 단일 세트. 일러스트는 빈상태/온보딩 한정.

## 5. 디자인 시스템 (토큰 + 컴포넌트)

### 5.1 토큰 (라이트·다크 듀얼)
- **Color**: `brand.{navy,azure,sky}` · `neutral.0–950` · `heat.{attention,caution,warning,danger}`(불변) · `semantic.{success,info,warning,danger}`(heat와 네임스페이스 분리) · `surface/border/text` 역할토큰(모드별 매핑).
- **Type/Space/Radius/Shadow/Motion/Z** 토큰화. 모든 컴포넌트는 역할토큰만 참조(원시 hex 직접참조 금지).
- 구현: `frontend/src/theme.ts` v2로 확장 + `cssVariablesResolver`로 다크모드 변수. Figma 토큰 ↔ 코드 토큰 1:1.

### 5.2 컴포넌트 인벤토리
- 계승(Mantine): Button/Card(Paper)/Badge/Table/Tabs/Select/DatePicker/Dropzone/Stepper/Modal/Alert/Notifications/Tooltip/Loader.
- **신규/재설계**:
  - `RiskHero` — 현재 위험단계 대형 상태 카드(색·라벨·체감온도·추세 화살표).
  - `KpiTile v2` — 수치+델타+스파크라인.
  - `ChartTheme` — recharts 공통 테마(축·그리드·툴팁·단계 임계선·다크 대응).
  - `RiskMapCard` / `RiskMap` — Leaflet 지도(마커=단계색).
  - `CurrentWeatherWidget` — 내부 vs 외부 비교·밀폐경고.
  - `AppShell`(네비) · `EmptyState`/`ErrorState`/`Skeleton` 표준.
- **데이터 비주얼 가이드**: 단계 임계선 항상 표기, 색맹 안전(색+패턴/라벨 병행), 툴팁 단위·시각 통일, 다크모드 축/그리드 대비.

## 6. 정보구조(IA) & 네비게이션 개편

### 6.1 현재 → 개편
- 현재: `① 계정 → ② 기기등록 → ③ 업로드 → ④ 대시보드`(위저드) + 관리자 토글. 상태가 URL에 없음.
- 개편: **듀얼 모드**
  - **온보딩 모드**(최초·무데이터): 위저드 유지하되 정제(진행·도움말 강화).
  - **운영 모드**(데이터 보유): **상시 네비(AppShell)** + 대시보드 우선.

### 6.2 신 IA 맵
```
케이웨더 안전보건 대시보드
├─ 대시보드        (위험 히어로·KPI·차트·현재날씨·지도 미니)
├─ 위험 지도        (전체 지도·사업장별 단계)
├─ 리포트          (일일/기간·PDF/Excel·미리보기)
├─ 기기 · 사업장     (등록·메타·지오코딩)
├─ 설정            (임계·표시·테마(라이트/다크)·계정)
└─ 관리자 ▸        (운영자 전용 — 트래픽·테넌트·로그)
```

### 6.3 반응형 네비
- 데스크톱: 좌측 **사이드바**(접이식) + 상단 컨텍스트 바(기기/일자/기간).
- 모바일: 하단 **탭바**(대시보드·지도·리포트·더보기) + 시트형 필터.
- **라우팅 도입**: 현 `step` 상태 → URL 라우팅(`react-router-dom`). 딥링크·뒤로가기·새로고침 맥락 보존, 리포트/지도 공유 링크 가능. (리팩토링 항목 §12)

## 7. 핵심 화면 재설계 (와이어 개요)

### 7.1 대시보드 (데스크톱)
```
┌───────────────────────────────────────────────────────────────┐
│  [☰] 케이웨더   기기▾  기준일자▾  기간▾            라이트/다크◑ 계정▾ │
├──────────────┬────────────────────────────────────────────────┤
│ ◼ 대시보드     │  ┌── RISK HERO ─────────┐ ┌ 현재 외부날씨 ───┐ │
│ ◻ 위험 지도    │  │  위험 38℃↑  ●위험      │ │ 외부 31.2℃ / 내부 │ │
│ ◻ 리포트      │  │  현재 체감 36.4℃ ▲     │ │ 36.4℃  Δ+5.2 ⚠밀폐│ │
│ ◻ 기기·사업장  │  └──────────────────────┘ └─────────────────┘ │
│ ◻ 설정        │  [KPI 최고체감][KPI 최고온도][KPI 33↑누적][KPI 평균습도]│
│ ─────────     │  ┌ 시계열(온·습도/체감, 임계선) ───────────────┐ │
│ ◻ 관리자 ▸    │  └────────────────────────────────────────────┘ │
│               │  ┌ 내·외부 비교 ────────┐ ┌ 위험지도(미니) ─────┐ │
│               │  └──────────────────────┘ └────────────────────┘ │
│               │  ┌ 폭염 단계별 안전조치(현재 단계 강조) ─────────┐ │
└──────────────┴────────────────────────────────────────────────┘
```
- **RiskHero**가 최상위 위계(위험 직관). KPI는 델타·스파크라인. 단계별 가이드는 현재 단계 자동 강조.

### 7.2 위험 지도 (전체)
- Leaflet 지도 + 사업장 마커(단계색)·클러스터·팝업(기기·현재 체감·최근 측정). 사이드 리스트 동기 선택. 모바일=전체화면 지도 + 하단 시트.

### 7.3 리포트
- 좌: 조건(기기·일자·기간) / 우: 미리보기(일일) + 생성 버튼(PDF·기간PDF·Excel). 생성중 모달. 모바일=세로 스택.

### 7.4 기기·사업장
- 등록 폼(주소검색·지오코딩) + 관리 테이블(편집·삭제). 모바일=카드 리스트(테이블→카드 변환).

### 7.5 온보딩 / 인증
- 리브랜드 적용 로그인(이미 Mantine화). 무데이터 신규는 위저드(기기→업로드)로 유도, 운영 모드 진입 시 상시 네비로 전환.

### 7.6 관리자
- 운영 KPI·추이 차트·테넌트/로그 테이블(이미 Mantine화) → 새 토큰·다크 대응·반응형 보강.

### 7.7 모바일 원칙
- 1열 스택, 테이블→카드, 컨텍스트 필터=바텀시트, 위험 히어로 풀블리드, 큰 터치(≥44px), 다크 기본 옵션.

## 8. 반응형 & 접근성

- **브레이크포인트**: xs/sm/md/lg/xl(Mantine). 데스크톱 멀티컬럼 ↔ 모바일 단일컬럼 규칙 문서화.
- **그리드/터치**: 8pt 스페이싱, 터치 타깃 ≥44px, 모바일 폼 풀폭.
- **A11y(WCAG 2.2 AA)**: 본문 대비 ≥4.5:1·대형 ≥3:1, **단계색은 색+텍스트/아이콘 병행**(색맹 안전), 포커스 링·키보드 내비·스크린리더 레이블, `prefers-reduced-motion`, 다크모드 대비 별도 검증.
- **다크모드**: 역할토큰 듀얼 매핑, 차트/지도/단계색 다크 대비 보정, 시스템 설정 연동 + 수동 토글.

## 9. 신기능 디자인 통합

- **위험지도(Leaflet)**: 의존성 `react-leaflet`+`leaflet`. 마커=단계색·클러스터·팝업·미니/전체 2뷰. 좌표 없는 기기 처리(안내). 타일 출처 라이선스 표기.
- **현재 외부날씨 위젯**: 백엔드 `/api/weather/current`(배포 완료) 연결. 외부 vs 내부 체감 비교·Δ·**밀폐형 경고**·관측시각/지역. 대시보드 히어로 옆 배치.
- (옵션) **알림/경보 센터**: 임계 초과 시 notifications + 이력. 차기 검토.
