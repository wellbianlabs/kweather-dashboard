# 컴포넌트 카탈로그 — 디자인 커스텀 워크플로우

> 작업자가 모듈별로 디자인을 직접 조절하고, 그 결과를 에이전트에게 지시해 코드에 반영하는 루프.
> **단일 진실원본 + 즉시 동기화**: 카탈로그는 `src/components/*` 의 *실제 컴포넌트*를 import 해 렌더하므로,
> 컴포넌트나 `theme.ts` 가 바뀌면 **Vite HMR로 카탈로그에 즉시 반영**됩니다(새 파일/빌드 불필요).

## 접근
- 로컬: **http://localhost:9999/catalog.html**
- 네트워크: http://192.168.0.9:9999/catalog.html
- 실앱(`/`)·대시보드 목업(`/mockup.html`)과 분리된 별도 dev 엔트리. 프로덕션 빌드엔 미포함.

## 화면 구성
```
┌ 좌: 모듈 네비 ─┬ 상단: 글로벌 테마 컨트롤 ───────────── [테마 지시문 복사] ┐
│ 파운데이션      │  [브랜드 프리셋▾] [라운드 sm/md/lg] [🌙] ● HMR 동기화        │
│ · 컬러 토큰     ├──────────────────────────────────────────────────────────┤
│ · 타이포        │  컴포넌트 제목 · 대상파일          [이 컴포넌트 지시문 복사]  │
│ · Button        │  [노브: size▾  단계▾  상태⃝ …]                              │
│ 대시보드        │  ┌ 라이브 프리뷰 캔버스(프리셋·라운드·다크 적용) ─────────┐ │
│ · KPI 카드 …    │  └──────────────────────────────────────────────────────┘ │
└────────────────┴──────────────────────────────────────────────────────────┘
```

## 워크플로우 (작업자 → 에이전트)
1. **고른다** — 좌측에서 모듈 선택.
2. **조절한다(라이브)**
   - *전역 톤*: 상단 **브랜드 프리셋**(현재 KW / A·Signal / B·Clear Sky / C·Control Room), **라운드**, **라이트/다크** → 프리뷰가 즉시 리컬러.
   - *컴포넌트별*: 본문 **노브**(size·위험단계·상태 등) → 프리뷰 즉시 변경.
3. **지시문을 뽑는다** — 우측 **"이 컴포넌트 지시문 복사"** 또는 상단 **"테마 지시문 복사"** 클릭 → 구조화된 지시 텍스트가 클립보드에 복사됨.
   - 컴포넌트 지시문엔 `대상 파일 / 현재 설정 / 원하는 변경(작성란)` 이 포함 — 작성란을 채워 의도 명시.
4. **에이전트에게 붙여넣는다** — 채팅창에 그대로 붙여넣고 전송.
5. **에이전트가 반영** — `theme.ts` 또는 해당 `src/components/*.tsx` 수정.
6. **즉시 동기화** — 저장 순간 **HMR로 카탈로그·실앱·목업 모두 갱신**. 새로고침 불필요.

> 예시 지시문(자동 생성):
> ```
> [테마 변경 지시] frontend/src/theme.ts 에 적용해줘:
> - primaryColor 'kw' 팔레트(10단계)를 아래로 교체 (프리셋: A · Signal (Azure)):
>   kw = ["#eaf2fb", … ,"#073354"]
> - defaultRadius = 'lg'
> ```
> ```
> [컴포넌트 변경 지시] Badge · HeatBadge
> - 대상 파일: src/components/HeatBadge.tsx
> - 현재 카탈로그 설정: {"size":"lg","level":"danger"}
> - 원하는 변경: 기본 size를 lg로, 모서리를 더 둥글게.
> ```

## "즉시 최신 동기화" 보장 방식
- 카탈로그 스토리는 컴포넌트를 **복제하지 않고** `import { X } from "../components/X"` 로 **직접 참조**.
- 따라서 에이전트가 컴포넌트를 고치면 **그 컴포넌트의 모든 사용처(실앱·목업·카탈로그)가 동일 소스로 즉시 반영**.
- 상단 브랜드 프리셋은 `theme.ts` 의 `kw` 팔레트를 **통째로 스왑**해 미리보는 것 → 확정 시 지시문으로 `theme.ts` 에 굳히면 전 화면에 영구 적용.

## 확장 (스토리 추가)
- `frontend/src/catalog/stories.tsx` 의 `STORIES` 배열에 한 항목 추가:
  ```ts
  { id:"myComp", group:"대시보드", title:"내 컴포넌트", file:"src/components/MyComp.tsx",
    knobs:[{type:"select",key:"size",label:"size",options:["sm","md"],default:"md"}],
    render:(k)=> <MyComp size={k.size}/> }
  ```
- 노브 타입: `select · boolean · number · text`. 데이터가 필요한 컴포넌트는 `src/mockup/data.ts` 의 목 데이터 사용.

## 제약 / 메모
- 상단 프리셋·라운드·다크는 **프리뷰 전용** — 실제 적용은 "테마 지시문 복사 → 에이전트 반영" 후 확정.
- API에 강결합된 화면(예: 관리자 대시보드)은 카탈로그에서 제외(인증 필요). 실앱에서 확인.
- 색 프리셋 A/B/C는 기획서 §4 리브랜딩 후보. **택1 확정 시 그 팔레트를 `theme.ts` 에 반영**하면 카탈로그/목업/실앱이 한 번에 새 톤으로.
